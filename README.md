# Mario Lab · PPO 强化学习控制台

## 1. 启动和安装

### 本机启动

在项目根目录双击 **`启动.bat`**，浏览器会打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。本机已安装运行环境，可以直接启动。

更新项目后，先退出原服务窗口，再重新运行 `启动.bat`，并刷新浏览器。

### 首次安装或换一台 Windows 电脑

1. 将完整工程解压到本地目录，推荐使用英文路径。
2. 双击 **`安装.bat`**，等待安装完成。首次安装需要联网；脚本会在项目目录准备 Python 3.11 和运行依赖，无需自行安装 Python、Node.js 或 Visual Studio。
3. 双击 **`启动.bat`**，进入网页。

默认使用 CPU，纯 CPU 电脑也能训练和演示，不要求特定 CPU 型号。有 NVIDIA 显卡且希望使用 GPU 训练时，先安装显卡驱动，再运行 **`安装CUDA.bat`**，安装完成后重启服务。系统会自动检测 CUDA，不可用时回退 CPU。

已创建的 Python 环境不适合直接搬到其他电脑；换电脑后重新运行安装脚本即可。

### 快速体验

- **直接观看 Agent 玩游戏**：进入“模型演示”，选择“上游 PPO · Mario 1-1”，保留随机策略、种子 42、1 回合，点击“启动独立评估”。
- **开始训练**：点击“新建训练”，填写训练步数等参数，选择从零开始或已有权重，然后启动训练。

预训练模型可直接用于演示；从零学会通关需要持续训练，时间取决于电脑性能。

### Linux / macOS 启动

准备 Python 3.11 和系统 C++ 编译器后，在项目根目录执行：

```bash
python3.11 scripts/setup.py
.venv311/bin/python scripts/serve.py
```

这些平台本次未进行实机验收；当前已验证的是 Windows x64 的 CPU 运行路径。

## 2. 前端模块功能

### 新建训练

页面右上角的“新建训练”用于创建 PPO 实验，可以设置任务名称、新增训练步数、计算设备、并行环境数和 CPU 线程数。

起始权重可选择“从零开始训练”，也可选择已有 checkpoint 继续训练。展开“PPO 与采集参数”后，可调整学习率、rollout 长度、batch size、更新轮数、保存间隔、评估间隔、随机种子和预览帧率等设置。

### 训练总览

查看当前训练状态和学习效果，顶部可切换历史训练任务。

- **统计卡片**：累计环境步数、已完成回合数、最远到达位置和近期评估通关率。这里的环境步数不是原始 NES 帧数。
- **训练控制栏**：查看运行时间、训练交互速度和完成进度，执行暂停、继续或安全停止。暂停会在安全训练边界生效；停止时保存模型。
- **实时环境预览**：显示训练 worker 0 的真实游戏画面。默认目标为 **30 FPS**，可在预览区切换 8 / 15 / 30 / 60 FPS 或关闭预览，运行中即可调整。画面上的 FPS 是浏览器实际收到并更新画面的速率；实际帧率受采样速度、梯度更新和电脑性能影响，训练暂停时画面也会暂停。
- **Agent 实时状态**：当前动作、Mario 世界坐标、当前回合奖励和步数、学习率、计算设备与可用的显存指标。
- **学习曲线**：平均回合奖励、探索进度、回合长度、独立评估通关率、Actor / Critic Loss 和策略熵，均来自真实训练或评估记录。
- **日志和导出**：查看训练进程日志，导出原始训练指标。

预览目标帧率只控制画面采集与显示，不改变 PPO 的训练步数或游戏动作。旧版进程中的训练任务需要安全停止、从 checkpoint 重新创建任务后，才能使用更新后的预览逻辑。

### 轨迹分析

查看 Mario 在单个回合中的运动路径，并比较不同回合。

- 从当前训练任务或独立评估记录中选择回合。
- 按成功 / 未通关筛选，按 Episode ID 搜索，并翻页查看历史记录。
- 最多同时对比 **4 条轨迹**，切换记录来源时保留已选路径，可比较成功与失败回合。
- 使用世界 X–Y 坐标绘制路径，标注通关或死亡终点。
- 拖动时间轴查看指定步的坐标、动作和奖励，并查看动作与奖励变化曲线。

轨迹回看展示的是坐标记录，原始游戏视频在“模型演示”中单独录制与回放。

### 训练历史

汇总本地保存的训练实验，展示任务名称、创建时间、算法、设备、累计步数、回合数量、最远位置和运行状态。

点击“查看曲线”返回对应任务的训练总览；点击配置按钮查看该任务的训练参数和 checkpoint 信息。

### 模型演示

加载 PPO 权重，在独立 Mario 环境中运行策略，查看模型实际表现。

- 选择随项目附带的预训练模型，或训练过程中保存的 checkpoint。
- 设置评估回合数、随机种子、单局步数上限，以及确定性 / 随机策略。
- 开启实时演示，查看真实游戏画面；需要时可停止评估。
- 勾选录制视频，评估结束后在网页回放或下载 **MP4**。
- 查看评估状态、完成回合、通关次数、通关率、最远位置和评估步数。
- 在评估记录表中重新打开历史结果和已有录像。

独立评估不会增加训练任务的累计步数。成功依据模拟器的 `flag_get` 信号判定，不只看 X 坐标。

### 公共状态与数据保存

侧栏展示当前实验、运行状态和计算模式，顶部显示本地服务连接状态。页面刷新或短暂断线后会恢复任务状态，关闭浏览器不会停止训练。

训练记录、模型、轨迹、日志和录像保存在项目的 `data` 目录。结束使用时，先对正在运行的任务执行“安全停止”，再关闭服务窗口。
