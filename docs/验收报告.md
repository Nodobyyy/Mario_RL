# 交付验收报告

日期：2026-10-27。验证平台：Windows x64、Python 3.11.9、PyTorch 2.4.1+cpu；未使用 CUDA。

## 已完成的真实验证

- 预训练策略 CPU 推理：随机策略、seed=42，在 329 个 Agent 环境步获得 `flag_get=True`，世界 X=3161。
- MP4 导出：真实 NES 帧，15 FPS，H.264；验收输出约 205 KB。样例为 `examples/cpu-pretrained-clear.mp4`。
- 从零 PPO 训练：调用原始 `train_mario.main()`，真实参数更新；回合、奖励、loss 和策略熵持久化。
- 安全暂停：在已完成 256 步的 rollout 边界暂停，等待期间累计步数不增加；随后恢复采样。
- 安全停止：保存有效 PPO checkpoint 和匹配 VecNormalize；中途轨迹标为 interrupted。
- checkpoint 恢复：保留累计 SB3 timesteps 并新增训练步数，载入优化器和对应奖励归一化统计。
- 上游预训练微调：从精确累计 8,050,000 步恢复，在 CPU 完成 128 个新增步；成功兼容原 NumPy 2 pickle。
- 独立自动评估、最佳 checkpoint 标记、训练 / 评估回合隔离。
- Windows spawn：4 worker / 128 总步，以及 8 worker / 256 总步均完成。
- 训练画面与指标 WebSocket；逐步轨迹保存点数等于真实 Episode 长度。
- 后端 5 个测试全部通过，包含 NumPy 标量 JSON 持久化回归、控制状态、重连快照、轨迹筛选、浏览器来源检查，以及所有并行 worker 的全局进度聚合。
- TypeScript 类型检查、Vite 生产构建、pip 依赖一致性和带约束文件的安装预检通过。

机器可读的最后一次完整验收结果见 `acceptance-results.json`；基准见 `preview-benchmark.json`。

## 浏览器操作验收

通过真实页面创建 2048 步 CPU 训练，看到累计步数、9 个完成回合、最远世界 X=2745 和真实采样画面。刷新后任务状态和历史曲线恢复。

独立评估页面显示预训练成功回合、100% 的本次单回合通关率、329 个评估步与 MP4 回放。

轨迹页实际选中训练死亡回合与独立评估成功回合，跨任务对比世界坐标；滑块回到末步时正确显示 537 / 537、世界 X=2745、对应动作和奖励。真实截图见 `screenshots/trajectory-comparison.png`。

## 性能

1 个环境、1024 步、2 轮梯度更新、2 个 CPU 线程，0 / 8 FPS 预览交错测量各两次：中位数约 104.5 / 105.1 环境步每秒，差异约 +0.5%，未观察到显著下降。短测存在噪声，不推断其他机器绝对吞吐量。

这四次训练均显式请求 CUDA，但在无 CUDA 的 PyTorch 环境自动回退 CPU，并持久化 `device_fallback=True`。

## 验证边界

没有在本次环境实际进行 CUDA 训练，也没有在 Linux / macOS 实机验收；相关安装和设备分支已实现。CPU 从零训练的短测试验证功能和真实学习管线，不代表已经从零训练出新的稳定通关模型。

原策略确定性模式在当前兼容环境的一次评估未通关。默认演示采用已验证的随机策略 / seed=42；其他种子或数值环境不承诺每局成功。未把失败结果改写为成功。

初次开发中发现并修复的依赖、NumPy 序列化、JSON 标量、Windows spawn 问题都有日志；最终验收在修复后完整重新执行并通过。

## 预览帧率升级验证（2026-10-27）

训练预览默认目标改为 30 FPS，允许 0–60 FPS；预览区可在运行中切换档位。移除了原 WebSocket 约 10 FPS 的轮询瓶颈，只在最新帧文件变化时读取 / 解码。前端将高频画面状态移入独立组件，避免每张游戏帧导致六张学习曲线重建，并用 requestAnimationFrame 合并过期画面。

在隔离数据目录运行真实 CPU PPO，30 / 60 FPS 档位的 WebSocket 实测接收速率约 19.2 / 28.0 FPS，包含梯度更新期间没有新采样画面的时间。未将目标帧率表述为保证显示帧率。

验证了动态关闭预览后帧文件停止更新、训练累计步数继续增加，以及重新开启预览后无需重启 worker 即恢复画面。详情见 `preview-upgrade-results.json`，可通过 `scripts/verify_preview.py` 重现。

升级后后端 7 项测试通过，包含新增加的帧率边界与动态配置生效测试；TypeScript 检查与前端生产构建通过。README 已精简为启动 / 安装与前端模块说明。
